# Third-party source notices

The Button implementation is adapted from shadcn/ui's Radix Button, reviewed from its official registry on October 29, 2026:
<https://ui.shadcn.com/r/styles/new-york-v4/button.json>

The adaptation narrows variants/sizes, uses the minimal Radix Slot package, separates variants from component exports for refresh boundaries, and defaults a native button to `type="button"`.
